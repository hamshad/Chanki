# Phase 10: Tone Spike + Scoring
## Plan 10-01: Pitch Estimation & Shape Scoring

**Goal**: Prove the pitch estimation approach (pitchy-MPM) on real phones with a speaker-relative scoring function.

### Tasks
1. **Dependencies**:
   - Install `pitchy` for real-time pitch detection.
2. **Scoring Logic**:
   - Create `src/utils/scoring.ts`.
   - Implement `calculateToneScore(pitches: number[], targetTone: Tone): number`.
   - Convert absolute Hz values to relative pitch changes (e.g. semitones from base) so that a high-pitched voice and a low-pitched voice are scored identically based on shape.
3. **ToneSpike Component**:
   - Create a hidden route or just a component `src/components/ToneSpike.tsx` to test mic access, collect audio data, run MPM from `pitchy`, and output a shape score.
   - Do NOT upload any audio data (verify offline capability).
4. **Research Report**:
   - Write `.planning/research/tone-spike-report.md` documenting the approach, latency, accuracy on test samples, and the speaker-relative math.
