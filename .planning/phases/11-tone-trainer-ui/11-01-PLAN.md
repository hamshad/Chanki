# Phase 11: Tone Trainer UI
## Plan 11-01: Contour Graph + Divergence Feedback

**Goal**: User records a tone attempt and sees their live pitch contour drawn against the target tone shape, with a score and the diverging region called out after each attempt.

Depends on: Phase 10 (pitchy MPM capture, speaker-relative scoring, `analyzeCapture` states).

### Tasks
1. **Contour math** (`src/utils/toneContour.ts`):
   - Target templates for tones 1–5 as semitone trajectories over normalized time.
   - `toContour(pitches, steps)` — time-normalize a pitch track to `steps` samples, semitones vs base.
   - `compareContours(user, tone)` — offset-align user contour to target, return mean absolute error and the worst diverging zone (start / mid / end) so the UI can say *where* the attempt went wrong.
   - Unit tests: alignment invariance, zone detection, template shapes.
2. **Capture hook** (`src/hooks/useToneCapture.ts`):
   - Extract the mic loop from `ToneSpike` (getUserMedia → AnalyserNode → rAF → `Frame[]` + live `analyzeCapture`), exposing `start(kind)`, `stop()`, `mode`, `live`, `error`, `baseFreq` calibration.
   - Refactor `ToneSpike` onto the hook — its tests must keep passing.
3. **Live graph** (`src/components/ToneContour.tsx`):
   - Canvas 2D, devicePixelRatio-aware, redraws on `requestAnimationFrame` while recording (~60fps).
   - Draws grid, target template (dashed, tone color var), user contour (solid), worst-zone highlight after stop.
   - Pitch latency stays <100ms: 2048-sample window (~46ms) + rAF (~16ms) + MPM (~0.08ms) — no buffering or smoothing added in the path.
4. **Trainer page** (`src/pages/ToneTrainer.tsx`, route `/tone`):
   - Tone picker, calibrate button, record/stop, reuse `analyzeCapture` noise/silence badges.
   - After stop: shape score from `calculateToneScore` + divergence readout naming the worst zone with a plain-language hint.
5. **Verification**:
   - `npx vitest run` green (existing ToneSpike tests + new contour/hook tests).
   - `npm run lint`, `npm run build` clean.
   - Manual: `/tone` on desktop + phone — contour tracks live, score + divergence shown, DevTools Network shows zero audio upload.
