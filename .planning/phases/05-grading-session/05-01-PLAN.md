# Phase 5: Grading + Session
## Plan 05-01: Session Queue & Summary

**Goal**: User completes fast 20-card whole-card-graded sessions with weak sides retried and a summary at the end

### Tasks
1. **Session Queue Manager**: Update `ReviewSession.tsx` to handle a queue of cards.
   - When a user grades a card `Again`, add it to the back of the queue (or keep it in a retry list) so it is shown again within the same session.
   - Keep track of session stats: number of cards studied, accuracy (number of cards passed on first try vs total), etc.
2. **Session Summary UI**: Create a `SessionSummary.tsx` component that shows when the queue is empty.
   - Display count, accuracy, and next-due information.
   - Provide a button to go back to the home screen.
3. **Integration & Polish**: Update routing and `ReviewSession` flow to gracefully end the session and display the summary.
4. **Testing**: Write unit tests for the session queue logic and summary display.
